# Miss-Skill

คลังสกิล (Agent Skills) ของ Muse ประจำตัวผู้ใช้ — สกิลที่สร้างและสะสมจากการทำงานจริงกับ Livezala แต่ละสกิลเป็นโฟลเดอร์ที่มีไฟล์ `SKILL.md` เป็นหัวใจ (คำสั่ง + วิธีทำงาน) ตามมาตรฐาน Agent Skills

## สกิลในคลัง

| สกิล | ใช้ทำอะไร |
|---|---|
| `agent-bridge` | เช็กและส่งข้อความระหว่าง Muse กับ Grok Bot ผ่าน Agent Bridge (bridge.livezala.com) |
| `drama-producer` | รับบทผู้จัดละครสั้น: วางเรื่อง แตกบท และบันทึกงานจริงเข้า Livezala Member Studio ผ่าน API |
| `verify_before_delivery` | ตรวจงานที่มอบหมาย/ร่างส่งมอบ เทียบกับข้อมูลดิบต้นทางด้วยตัวเอง ก่อนอ้างว่างานเสร็จ |
| `recovered-skill-notes` | โน้ตสกิลที่กู้คืนไว้เป็นข้อมูลอ้างอิง |

## วิธีใช้

สกิลเหล่านี้ใช้งานกับ Muse (พี่ใหญ่) ในระบบของผู้ใช้โดยตรง ไฟล์ต้นฉบับใช้งานจริงอยู่ที่ `~/workspace/custom-skills/` ในเครื่องของ Muse — repo นี้เป็นคลังเก็บและสำรองบน GitHub อัปเดตตามงานจริงเป็นระยะ

> ในคลังนี้ไม่มี API Key หรือข้อมูลลับใด ๆ (ตรวจก่อน push ทุกครั้ง)
