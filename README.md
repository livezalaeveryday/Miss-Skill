# Miss-Skill

สกิลผู้เชี่ยวชาญด้าน **ความผิดพลาดของ AI** — เริ่มใหม่จากสกิลเดียว เพื่อสะสมความเชี่ยวชาญเรื่องการจำแนก วินิจฉัย และป้องกันไม่ให้ AI พลาดซ้ำ

หลักคิด: ไม่กลัวความพลาด อยากให้พลาดเยอะ ๆ เพื่อจะได้ไม่พลาดแบบเดิมซ้ำ — ตัวชี้วัดที่แท้จริงคือ "การพลาดซ้ำ" ไม่ใช่จำนวนครั้งที่พลาด

## สกิลในคลัง

| สกิล | ใช้ทำอะไร |
|---|---|
| `ai-failure-expert` | ผู้เชี่ยวชาญด้านความผิดพลาดของ AI: แผนที่ความผิดพลาด 10 แบบ, วงจรวินิจฉัย 8 ขั้น (หา ground truth → จำแนก → หาราก → สร้างรั้วกันซ้ำ → จดบันทึก → ตรวจซ้ำ), รูปแบบบันทึกความพลาด และการเก็บกวาดคราบที่ความพลาดทิ้งไว้ในความจำ/โค้ด/นิสัย |

## รูปแบบสกิล

แต่ละสกิลเป็นโฟลเดอร์ที่มี `SKILL.md` เป็นหัวใจ (คำสั่ง + วิธีทำงาน) และ `skill.yaml` เป็นข้อมูลกำกับ ตามมาตรฐาน Agent Skills โครงสร้างเดียวกับที่ใช้ในระบบ Muse (พี่ใหญ่) ของผู้ใช้

> คลังนี้ไม่มี API Key หรือข้อมูลลับใด ๆ (ตรวจก่อน push ทุกครั้ง)
